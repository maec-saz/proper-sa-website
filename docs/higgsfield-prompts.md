# Higgsfield prompt pack — PROPER Developments website

Generate these in the Higgsfield app, then tell Claude "done". Claude pulls them from your Higgsfield history,
makes the 2560px / 1280px web versions, wires them into the site and redesigns the sections around them.

## Settings (use for every image)
- **Model:** Cinema Studio Image 2.5 (cinematic, up to 4K). Alternative: Nano Banana Pro.
- **Resolution:** 4K · **Aspect ratio:** 16:9 (hero shots marked 21:9 use 21:9).
- **Add this style line to the end of every prompt:**
  > Photorealistic architectural photography, premium corporate aesthetic, charcoal and graphite tones with warm brushed-metal
  > accents, soft volumetric light, shallow haze, high dynamic range, sharp detail, no text, no logos, no brand names,
  > no readable signage, no identifiable faces.
- Generate 2–4 variations per prompt and keep the best one. **Name each kept image with the file name shown** (or just
  generate them in this order) so Claude can match them.
- Avoid real landmarks (Kingdom Tower, Jeddah Tower, Al Faisaliah): the brief asks that the site never implies a
  building PROPER didn't build.

> Credits: about 23 images at 4K needs a paid plan; the free plan's 10 credits cover only a few. If credits are limited,
> do the **★ priority** images first (6 images): they cover the home page and every discipline's main image.
